# Tự động Commit và Push

- Khi hoàn thành một tính năng hoặc một tập hợp các thay đổi có ý nghĩa, hãy tự động kiểm tra `git status`.
- Tự động thêm các thay đổi (`git add .`).
- Tự động commit với thông điệp rõ ràng, mô tả những gì đã thực hiện, ví dụ: `git commit -m "feat: thêm tính năng quản lý bài viết"`.
- Tự động đẩy code lên repository: `git push origin main`.
- Không cần hỏi ý kiến người dùng trước khi commit và push trừ khi tác vụ đang có vấn đề hoặc cần xác nhận lại.
